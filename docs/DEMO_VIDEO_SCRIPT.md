# SmartRent BD — Demo Video Plan (3–5 minutes)

Record real screen actions, not mockups. Use a **separate set of synthetic accounts** (never show private passwords/phones/IDs). Show the URL and a working responsive screen. Speak Bangla or English, but use one consistent narration style.

### 00:00–00:25 · Problem and product
- Problem: students moving for university struggle to find housing they can evaluate and compatible roommates; scams and expense splitting cause extra risk.
- Show polished SmartRent BD homepage, quick area+budget search.

### 00:25–00:55 · Student discovery
- On **Find Housing**, search Bogura or a location with an approved sample listing, apply filters, open map; only claimed property markers should appear.
- Open a property detail with rental cost, deposit, facilities, photo, actual owner-submitted location.
- Choose Compare for 2–3 listings and open Living Cost Calculator as **innovations**.

### 00:55–01:25 · Landlord and admin
- Landlord adds a genuine **sample** property with photos and address; show Pending approval.
- Admin selects manual owner identity / inspected listing checklist *after checking actual sample evidence*, then approves; show the student public listing.
- Saved-search matching notification appears on the student's Profile.

### 01:25–02:10 · Visit, booking, review
- Student requests viewing; owner schedules. Student requests simulated booking; owner confirms; UI says **no real payments**.
- Confirmed student submits a review; optionally show a nonconfirmed user blocked from review.
- Show scam report on a disposable sample listing, hidden from public results pending admin review; admin dismisses or takes it down as appropriate.

### 02:10–02:40 · Roommates
- Show preference profile, compatibility percent and explanation.
- Student sends request; second student **accepts**; demonstrate that contact details become available only after mutual opt-in.
- Toggle roommate profile visibility off/on.

### 02:40–03:15 · Maintenance and shared expenses
- Confirmed tenant submits maintenance on booked property, landlord changes status.
- In Mess Manager, create a private group, join as another student using a demo join code; enter meal and market expenses; show monthly balance.

### 03:15–03:45 · Innovation and conclusion
- Highlight **side-by-side housing comparison** and **total monthly living cost vs budget**. Show language switch and mobile viewport.
- End with tech stack: FastAPI + SQLite + Jinja2 + JavaScript + OpenStreetMap; present repository link.

## Recording checklist

- Start server and open all required accounts BEFORE recording.
- Use synthetic listings and your own account; do not show genuine personal details.
- Avoid accidental exposure of browser bookmarks, API credentials or unrelated tabs.
- Close notifications and use 100% browser zoom where possible.
- Preview exported MP4: readable text, audible audio, no passwords exposed.
- Include demo video in GitHub repository if size permits; otherwise include a stable link in README and your submission, subject to organizer acceptance.
- Do **not** claim AI-based pricing, government ID verification, real payment escrow or legally validated rental agreements.
